# UNO онлайн

Игра для 2–6 игроков. Два режима:

- **С компьютером** — выбираете 1–3 соперников-ботов, игра начинается сразу.
- **С друзьями** — каждый играет со своего телефона или компьютера, подключение по коду комнаты из 5 символов или по ссылке. Создатель комнаты может добавить в лобби компьютерных игроков.

## Состав

```
server.js          — сервер (Node.js, без внешних зависимостей)
package.json
public/index.html  — интерфейс
public/app.js      — логика клиента
public/style.css   — оформление
public/fx.js       — анимации и звуки
public/sounds/     — записанные звуки (uno.mp3 — выкрик «UNO!», синтез голоса Piper, LibriTTS, CC BY 4.0)
```

## Запуск

Нужен Node.js версии 16 или новее. `npm install` не требуется.

```bash
node server.js              # порт 3000
PORT=8080 node server.js    # другой порт
```

Откройте `http://адрес-сервера:3000`, введите имя и нажмите «Создать комнату». Код или ссылку отправьте друзьям.

## Постоянная работа на сервере (pm2)

```bash
npm i -g pm2
pm2 start server.js --name uno
pm2 save && pm2 startup
```

## Nginx (домен + HTTPS)

Обновления идут через SSE (Server-Sent Events — поток событий от сервера), поэтому буферизацию нужно отключить:

```nginx
server {
    server_name uno.example.by;
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header Connection "";
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 1h;
    }
}
```

Если игра работает в подпапке (`location /uno/` → `proxy_pass http://127.0.0.1:3000/;`), ничего менять не нужно — клиент использует относительные пути.

## Настройки

Константы в начале `server.js`:

- `MAX_PLAYERS` — максимум игроков (6)
- `TARGET_SCORE` / `ROUND_MINUTES` — значения по умолчанию для цели партии (500) и времени раунда (10 мин)
- `AFK_SECONDS` — через сколько секунд за отключившегося игрока автоматически берётся карта и ход переходит дальше (30)
- `HAND_SIZE` — сколько карт раздаётся (7)
- `BOT_DELAY_MS` — сколько «думает» компьютер перед ходом (0,9–1,7 с)
- `BOT_UNO_CHANCE` — как часто компьютер не забывает крикнуть UNO (85%)

## Сохранение игр

Комнаты, карты, очки и история раундов сохраняются и переживают перезапуск сервера.

- **Свой сервер / VPS** — ничего настраивать не нужно: всё пишется в файл `data/rooms.json` (путь можно сменить переменной `DATA_FILE`).
- **Бесплатный Render** — файлы там стираются при каждом перезапуске и «засыпании», поэтому нужна внешняя база. Подходит бесплатный Upstash Redis:
  1. Зарегистрируйтесь на upstash.com → **Create Database** (Redis, регион Frankfurt).
  2. На странице базы в блоке **REST API** скопируйте `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.
  3. В Render: сервис → **Environment** → добавьте обе переменные → **Save Changes**.
  4. В логах при запуске появится строка «Хранилище: Upstash Redis».

## Настройки партии

Создатель комнаты выбирает на главном экране или в лобби:

- **время раунда** — ∞, 3, 5, 10, 15 или 20 минут. Когда время вышло, раунд выигрывает тот, у кого на руке меньше всего очков;
- **до скольки очков идёт партия** — 100, 200, 300 или 500;
- **перевод +2/+4** — на «+2» можно положить «+2» (любого цвета) или «+4», на «+4» — только «+4». Штраф копится, и тот, кому нечем перевести, берёт всю сумму и пропускает ход. Включено по умолчанию.

- **перехват (Jump-In)** — если у вас карта, точно совпадающая с верхней в сбросе (цвет и значение), её можно положить вне очереди, пока очередной игрок не сходил и не взял карту. Дальше игра идёт от перехватившего. Чёрными картами перехватывать нельзя, во время перевода +2/+4 — тоже. Если два игрока нажали одновременно, побеждает тот, чей запрос пришёл на сервер первым. Боты тоже перехватывают (`BOT_JUMP_DELAY_MS`, `BOT_JUMP_CHANCE`). Включено по умолчанию.

Чёрные карты («Закажи цвет» и «+4») можно класть в любой момент.

**Время на ход.** Если раунд идёт на время, на каждый ход даётся лимит: `TURN_MAX_SECONDS` (30 с) в начале раунда, дальше — одна восьмая оставшегося времени раунда, но не меньше `TURN_MIN_SECONDS` (4 с). Не успел — берёт карту и пропускает ход.

**Эмоции.** Кнопка 😀 рядом с «Взять карту» открывает панель: злость, хохот, радость, «круто», шок, «думаю», плач, любовь. Эмоцию видят все игроки, не чаще одной в 2,5 секунды.

## Важно

- Если обновить страницу, игрок вернётся в свою комнату со своими картами (сессия хранится в браузере).
- Хост — создатель комнаты. Он начинает раунды и может удалить игрока (в игре — только отключившегося).
- Все правила проверяет сервер: каждый игрок видит только свои карты.
